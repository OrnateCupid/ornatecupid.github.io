### 各类业务异常，报错，如何处理

使用全局异常处理器，让错误处理集中到一个地方

#### 例子

数据库插入重复字段会抛异常

方案一：先查询是否存在，若不存在再插入。问题：1.多线程下必然会有并发问题；2.查询拖性能

方案二：直接插入，处理可能抛出的异常。若无问题，插入成功；若有问题，可直接分析抛出的异常

#### 使用
1. @RestControllerAdvice 注解可将类注册为异常处理类，controller 及其一下所有抛出的异常都将被该类捕获
2. @ExceptionHandler 注解定义异常处理方法，可以指定方法处理哪些异常
```java
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(DuplicateKeyException.class)
    public Result handleDuplicateKeyException(DuplicateKeyException e) {
        log.error("数据库唯一约束冲突: {}", e.getMessage());
        return Result.error("数据已存在");
    }
    
    @ExceptionHandler
    public Result exceptionHandler(BaseException e) {
        log.error("未知异常：{}", e.getMessage());
        return Result.error("服务器出现未知异常");
    }
}
```

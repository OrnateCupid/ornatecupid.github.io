### 三种常见请求方式

1. URL 路径变量
    - 形如：`.../{id}`
    - 接收方式：`func(@PathVariable Long id)`

2. Query 参数 / 表单字段
    - Query 参数，形如：`/users?name=xxx&age=xxx`
        - 接收方式：
            1. 直接写一个变量 / 类接收，要求字段名必须和请求参数名完全一致
            2. 变量前加 `@RequestParam` 注解，可以指定名称 / 默认值
            - spring 内置格式转换器，eg: `ids=1,4,6,7` -> `List<Integer> ids`，使用自动格式转换**必须加 `@RequestParam` 注解**
            - 还可以配置自定义格式转换器
            
    - 表单，请求体格式为 `application/x-www-form-urlencoded` 或 `multipart/form-data`，并非结构化的 json 或 xml
        - 接收方式：直接用类接收

3. 请求体的结构化参数，JSON / XML
    - 请求体格式为 `application/json` 或 `application/xml`
    - 使用 @RequestBody 注解，请求体数据会自动反序列化为 java 对象

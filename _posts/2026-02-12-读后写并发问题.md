### 密码更新
1. 业务流程
    1. 查询原密码
    2. 验证是否相同，当前密码与原密码，原密码与新密码
    3. 更新密码
2. 问题
    - 属于经典读后写问题，可能出现：
        - 更新丢失，脏读，不可重复读，幻读
    - spring 的解决方式
        - 乐观锁 + 事务
        1. 数据库乐观锁：
        ```
            UPDATE table
            SET    col = newValue
            WHERE  id = ?
            AND  col = expectedOldValue;
        ```
        2. 方法加 @Transactional 注解，作为事务提交
        3. update 在 where 条件不满足时**不会抛异常**，需要判断 SQL 的返回值来检查是否更新成功，若失败，需要手动抛异常触发事务回滚

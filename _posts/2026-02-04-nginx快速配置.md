配置文件：/conf/nginx.conf

#### 1. 反向代理
- server 块：一个 server 块对应一个虚拟主机 / 服务器集群，反向代理在此配置
- 使用 location

```
    location /api/ {
        proxy_pass http://localhost:8080/admin/;
    }
```

- 意为：将所有向 http://ip/api/xxxxxxx 的请求转发至 http://localhost:8080/admin/xxxxxxx
    - xxxxxxx 是动态的

#### 2. 负载均衡
- 将 proxy_pass 的 ip 设为一组 ip 即可

```
upstream webservers {
    server 192.168.0.100:8080;
    server 192.168.0.101:8080;
    server 192.168.0.101:9090;
    ...
}

server {
    listen 80;
    server_name localhost;
    location /api/ {
        proxy_pass http://webservers/admin; # <--------
    }
}
```

- 负载均衡分配策略
    - 轮询，权重，ip 哈希，...

#### BTRFS 文件系统

- B-Tree File System
- 好处多多

#### 子卷

- 是一种逻辑分区
- 采用 btrfs 的分区可以分为多个子卷，每个子卷之间逻辑独立，共享整个物理分区
- 子卷的大小不用指定，会自动调整，很少出现某分区空间不足或浪费
- 作为逻辑分区，子卷可以单独挂载
- 子卷可以创建快照

#### 操作

1. 格式化 btrfs
```sudo mkfs.btrfs /dev/sda1```
2. 挂载
```sudo mount /dev/sda1 /mnt```
3. 创建子卷
```
sudo btrfs subvolume create /mnt/@
sudo btrfs subvolume create /mnt/@home
sudo btrfs subvolume create /mnt/@home-snap
sudo btrfs subvolume create /mnt/xxxx
# 查看子卷
sudo btrfs subvolume list /mnt
```
4. 挂载子卷
```
# 压缩模式 zstd
sudo mount -o subvol=@,compress=zstd          /dev/sda1 /mnt
sudo mount -o subvol=@home,compress=zstd      /dev/sda1 /mnt/home
sudo mount -o subvol=@home-snap,compress=zstd /dev/sda1 /mnt/home-snap
```

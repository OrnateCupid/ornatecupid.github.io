### 复杂动态 SQL

- 当某个数据库操作涉及多个表或复杂操作时，在 xml 写动态 SQL 会比在代码内用 MP 框架实现更简单

- 比如:

```java
    Page<Dish> pageInfo = new Page<>(dto.getPage(), dto.getPageSize());
    LambdaQueryWrapper<Dish> wrapper = Wrappers.lambdaQuery(Dish.class);
    wrapper.like(StringUtils.hasText(dto.getName()), Dish::getName, dto.getName())
            .eq(dto.getCategoryId() != null, Dish::getCategoryId, dto.getCategoryId())
            .eq(dto.getStatus() != null, Dish::getStatus, dto.getStatus())
            .orderByDesc(Dish::getCreateTime);
    Page<Dish> pages = dishMapper.selectPage(pageInfo, wrapper);
    long total = pages.getTotal();
    List<Dish> records = pages.getRecords();
    if (records.isEmpty()) {
        return new PageResult(total, records);
    }
    // 2. 收集所有出现的 categoryId
    Set<Long> idSet = records.stream()
            .map(Dish::getCategoryId)
            .filter(Objects::nonNull)
            .collect(Collectors.toSet());
    // 3. 构造 id - name 映射
    LambdaQueryWrapper<Category> wrapper1 = Wrappers.lambdaQuery(Category.class);
    wrapper1.in(Category::getId, idSet);
    List<Category> categories = categoryMapper.selectList(wrapper1);
    Map<Long, String> map = categories.stream()
            .collect(Collectors.toMap(Category::getId, Category::getName, (v1, v2) -> v1));
    // 4. 构造 vo list
    List<DishVO> list = records.stream()
            .map(dish -> {
                DishVO vo = new DishVO();
                BeanUtils.copyProperties(dish, vo); // 复制同名属性
                vo.setCategoryName(map.get(dish.getCategoryId()));
                return vo;
            }).toList();
    return new PageResult(total, list);
```

```xml
    <select id="selectPageWithCategory" resultType="com.sky.pojo.vo.DishVO">
        SELECT d.*, c.name AS category_name
        FROM dish d
        LEFT JOIN category c ON d.category_id = c.id
        <where>
            <if test="dto.name != null and dto.name != ''">
                AND d.name LIKE CONCAT('%', #{dto.name}, '%')
            </if>
            <if test="dto.categoryId != null">
                AND d.category_id = #{dto.categoryId}
            </if>
            <if test="dto.status != null">
                AND d.status = #{dto.status}
            </if>
        </where>
        ORDER BY d.create_time DESC
    </select>
```

- 总结
    - 单表简单 CRUD 或单表动态查询：用 MP
    - 多表联查：MP 有 MPJ 的 join 扩展依赖，可以让 wrapper 使用 join 方法；或者用 xml；或者多用几次 basemapper 的方法
    - 复杂多表操作：建议 xml

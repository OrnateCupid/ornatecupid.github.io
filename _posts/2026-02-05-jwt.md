#### JWT 令牌
1. 主流会话跟踪方案
    - 服务端创建和校验令牌
    - 客户端存储和携带令牌
    - 支持多端，集群可用
2. json web token
    - jwt 令牌以 base64 编码的 json 格式传输信息
    - 结构：`aaaaaaa.bbbbbbbbb.cccccc`
    1. header
        - 令牌类型 + 签名算法
    
    2. payload
        - 载荷信息 / 声明
        - **未加密**，不要存储敏感信息

    3. signature
        - 签名，保证 jwt 的安全性
        - 由 header + payload + 密钥 通过签名算法生成
        - 令牌任意部分遭到修改，签名都将不匹配，令牌失效
3. 注意事项
    - 令牌无法主动失效，必须设置过期时间

#### Filter 过滤器
1. 使用
    - 实现 Filter 接口的三个方法 init(), doFilter(), destroy()
        - init：项目启动时执行一次
        - destory：项目关闭时执行一次
        - doFilter：每次拦截一次执行一次
    - 配置过滤器
        - @WebFilter(urlPatterns = "/*") 注解指定过滤器拦截哪些请求
        - 启动类 @ServletComponentScan 注解开启 springboot 对 servlet 组件的支持
2. 详解
    1. filter 拦下请求后进入 doFilter() 方法，使用 filterChain.doFilter() 放行请求，请求执行完后还会返回 doFilter() 方法，因此还可以实现放行后的逻辑
    2. filterchain 过滤器链
        - 启用多个过滤器时构成过滤器链
        - 默认按照过滤器的类名字符串排序


#### Interceptor 拦截器
1. 使用
    - 实现 HandlerInterceptor 接口的三个方法 preHandle(), postHandle(), afterCompletion()
        - preHandle：拦截到请求后目标资源方法执行前执行；返回值 (bool) 决定是否放行
        - postHandle：目标资源方法返回后执行
        - afterCompletion：视图渲染完毕后执行（前后端分离后后端不需要渲染视图，不用）
    - 配置拦截器
        - 拦截器由 spring 管理，需要 @Component 注解
        - 配置类注册拦截器
            - 需要 @Configuration 注解，实现 WebMvcconfigurer 配置器接口
2. 详解
    1. 拦截路径
        - 拦截器注册器可以 addPathPatterns 也可以排除路径 excludePathPatterns，但顺序无关，spring 会先收集全部需要拦截的路径，再去除需要放行的路径。如果不配置 add 和 exclude，默认拦截所有路径；只配置 exclude，等价于只排除 exclude 路径；只配置 add，则只拦截 add 路径
        - "/*" 表示一级路径，只能拦截 "/xxxx"，不能拦截 "/aaaa/bbbb"
        - "/test/*" 同理，只能拦截 "/test/xxxx"，不能拦截 "/test/aaaa/bbbb"
        - "/**" 表示任意级路径
        - "/aaa/*/bbb" 可以拦截特定模式
    2. 过滤器-拦截器
        - 先过滤器，后拦截器
        - 过滤器是 servlet 规范的内容，范围比 spring 更大，过滤器能拦截项目的所有资源，拦截器只能拦截 spring 管理的资源
    3. 拦截器链
        - 注册时有 order 选项

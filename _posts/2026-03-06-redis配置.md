### 关于 spring 使用 jackson 序列化 LocalDateTime 对象

- 当为 Redis 模板配置值序列化器为 jackson 时，存入时间对象时报错
- 原因：jackson 默认不支持序列化 java 8 的时间日期对象
- 解决办法：
    1. 引入 `com.fasterxml.jackson.datatype:jackson-datatype-jsr310` 模块
    2. 配置 `ObjectMapper` 注册 `JavaTimeModule`，让序列化器支持

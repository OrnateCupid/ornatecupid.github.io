### 启用

- 通过配置类创建 Redis 模板对象 bean `RedisTemplate`
    - 可手动配置各种序列化器
- 引入 redis 依赖后可直接自动注入 SpringRedisTemplate，使用字符串序列化

### Redis 的存储本质

- redis 存储的 key 和 value 都是**字节数组**，需要序列化
- 针对不同语言的对象，序列化需要由客户端自行实现
- eg：json 序列化 / 反序列化: `客户端 k / v 对象` <-> `json 字符串（跨语言）` <-> `Redis 字节数组`
